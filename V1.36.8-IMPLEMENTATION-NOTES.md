# V1.36.8 — Adam Assistant Interaction Controller

This build introduces one authoritative controller for Home Adam assistant controls.

## Interaction contract
- Native assistant buttons remain the source of truth via `data-adam-action`.
- One window-level capture listener handles click activation.
- One window-level capture listener handles Enter/Space and Escape.
- No coordinate hit-testing is used by the controller.
- No assistant-specific pointerup/touchend fallback is required.
- The controller guards against duplicate activation from competing event paths.
- Existing Home mascot sizing and caption removal remain unchanged.
